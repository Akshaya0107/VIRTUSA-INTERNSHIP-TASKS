# M.Tech Internship – Programming Tasks

This project contains simple, internship-ready code for all 9 programming tasks, kept easy to understand and explain in viva examinations.

---

## 📁 Project Structure

```text
VIRTUSA PROJECT/
├── Java/
│   ├── ArraySum.java              # 1. Sum of all array elements
│   ├── PowerWithoutMathPow.java   # 2. Compute a^b without Math.pow()
│   ├── SelectionSort.java         # 3. Implement Selection Sort
│   └── README.md                  # Java notes & viva dry runs
├── TypeScript/
│   ├── src/
│   │   ├── sumOfDigits.ts         # 4. Find sum of digits of a number
│   │   ├── employeeCrudService.ts # 5. Employee CRUD Service (Interface + Class)

│   ├── tsconfig.json
```

## 🚀 How to Run

### Java
```bash
cd Java
java ArraySum.java
java PowerWithoutMathPow.java
java SelectionSort.java
```

### TypeScript
```bash
cd TypeScript
npm run task1
npm run task2
npm run task3
```

### JavaScript
```bash
# Task 7
node JavaScript/groupWordsByFirstChar.js

# Tasks 8 & 9
# Open JavaScript/themeSwitcher/index.html and JavaScript/webComponent/index.html in any browser.
```
